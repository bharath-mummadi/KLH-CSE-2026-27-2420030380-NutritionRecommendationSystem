# Dataset Sources

This project uses three datasets. None share a common key, so they are
linked through a two-stage pipeline rather than a single database join.

## 1. NHANES 2017–2018 (Health & Biomarker Data)
- **Portal:** https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017
- **Files used:** DEMO_J, BMX_J, DR1TOT_J, MCQ_J, GHB_J, GLU_J, TCHOL_J, HDL_J, PAQ_J
- **Direct download pattern:** `https://wwwn.cdc.gov/Nchs/Nhanes/2017-2018/<FILENAME>.XPT`
- **Join key:** `SEQN`
- **Status in this repo:** Not downloaded (sandbox has no internet). A synthetic
  stand-in with the same field structure is in `data/synthetic_nhanes.csv`,
  generated by `src/generate_synthetic_data.py`.

## 2. USDA FoodData Central (Nutrient Reference Data)
- **Portal:** https://fdc.nal.usda.gov/download-datasets.html
- **Recommended package:** Foundation Foods or SR Legacy
- **Role:** Provides verified nutrient values per food item; used both as a
  ground-truth reference and as the retrieval source for the RAG layer.

## 3. Food.com Recipes and Interactions (Recipe & Rating Data)
- **Portal:** https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions
- **Files:** `RAW_recipes.csv`, `RAW_interactions.csv`
- **Access:** Requires a free Kaggle account; download via UI or Kaggle API:
  ```bash
  pip install kaggle
  kaggle datasets download -d shuyangli94/food-com-recipes-and-user-interactions
  ```
- **Role:** Provides real recipes and user ratings for hybrid (content +
  collaborative) recommendation. Ingredients are linked to USDA nutrient
  entries via fuzzy text matching (see `docs/methodology.md`).

## Switching from synthetic to real data
Replace `load_data()` in `src/preprocess.py` with a `.XPT` loader for the
real NHANES files (see comment block at the top of that file), then re-run
the pipeline — no other code changes are required.
